# Algorithm-Visualizer

## Project Description:
Algorithm Visualizer is a simple web-based project that helps users understand how different algorithms work through visual representation. It is built mainly using **HTML**, **CSS**, and **JavaScript**, focusing on clarity, interaction, and ease of learning.
